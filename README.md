# CST8504 — Canadian Air Quality Prediction Dashboard

## Project overview

This project analyzes air pollutant measurements from Canada's **National Air Pollution Surveillance (NAPS) Program**, using a dataset published through the Government of Canada's Open Government Portal. The project explores relationships between pollutants, differences between monitoring stations, and changes over time. It also trains regression models to predict pollutant measurements from other measured pollutants.

**Dataset source:** [Government of Canada Open Data](https://open.canada.ca/data/en/dataset/1b36a356-defd-4813-acea-47bc3abd859b)
